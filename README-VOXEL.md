# Voxel Realms HD

A from-scratch browser voxel sandbox built with Three.js. It is an original project and does not use Minecraft assets or code.

## Play

Open `game.html` on GitHub Pages. The page loads Three.js from jsDelivr, so there is no npm/build step.

## Current build

- Procedural seeded-looking terrain
- Grass, dirt, stone, sand, wood, leaves, glass and planks
- Trees
- First-person mouse look
- WASD movement, sprint and jumping
- Block raycasting
- Mine and place blocks
- Hotbar selection
- Shadows, fog, tone mapping and atmospheric lighting
- Responsive presentation

## Roadmap

Chunk streaming and greedy meshing are next, followed by texture atlases/PBR, caves and ores, inventory/crafting, save/load, biomes, water, weather, mobs, tools, audio, controller/touch input and multiplayer-ready world architecture.
